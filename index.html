Comparer les appareils

Les appareils mobiles, dans le cadre du Responsive Web Design, se rapportent à une valeur fondamentale qui est la largeur CSS (ou "device-width"), exprimée en pixels indépendants du dispositif CSS. Cette valeur dépend à la fois du navigateur et des paramètres de zoom de l'utilisateur.
